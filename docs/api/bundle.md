# `aegean.bundle`

Portable, deterministic, SHA-256-verified research bundles
(`aegean-research-bundle/1`). Packages a corpus (or license-clean retrieval
pointer for non-commercial datasets), citations (`citations.json`,
`CITATIONS.bib`, `CITATIONS.txt`), workbench workspace state, editable review
tables (with `.companion.json` snapshots), and analysis receipts into a single
verifiable `.zip` archive.

::: aegean.bundle
