# `aegean.browser`

Local Greek visual corpus browser server and JSON analysis service
(`serve`, `create_server`, `BrowserServer`). Serves an interactive three-pane
web reader over loopback for any bundled, cached, or open-licensed Greek text
in PyAegean — with toggleable interlinear glosses, parallel translations,
hover dependency highlighting, parallel grammar/lexicon/context/stats
inspectors, Strong's root trees, patristic commentaries, metrical scansion,
FTS5 search, live NLP engine toggles, and CoNLL-U/CSV/JSON export.

::: aegean.browser
