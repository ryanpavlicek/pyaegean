# `aegean.search`

Unified diacritic-insensitive full-text search with lazy SQLite FTS5 sidecar
indexes across registered corpora, the Greek New Testament (all 9 editions),
the 55-book Swete Septuagint, the 33-volume *Patrologia Graeca*, Perseus /
First1KGreek works, and local `.json`/`.json.gz`/`.db` files.

::: aegean.search
